# Recicle Já

Site do projeto Recicle Já, uma proposta de plataforma para integrar condomínios residenciais, cooperativas de catadores, prefeituras e indústria recicladora na coleta seletiva.

Publicado com GitHub Pages a partir da raiz da branch `main`.

## Estrutura

- `index.html`: página única do site.
- `assets/css/style.css`: estilos.
- `assets/img/`: capturas de tela do protótipo (extraídas do relatório comercial).
- `docs/`: artigo e relatório comercial em PDF.

## Visualização local

Abra `index.html` no navegador, ou rode um servidor estático na raiz:

```powershell
python -m http.server 8000
```

Em seguida, acesse `http://localhost:8000`.
